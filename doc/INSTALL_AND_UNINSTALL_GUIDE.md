# 行雲_繁-A (Floating Cloud IME) 安裝與卸載標準操作指南

本文檔詳細記錄「行雲_繁-A」輸入法的完整安裝、升級與卸載標準作業流程，並深入解析 macOS 系統設定之安全邊界。

---

## 1. 快速安裝（推薦）

1. 掛載最新發布的 `行雲_繁-A_安裝磁碟.dmg`。
2. 雙擊執行「**安裝行雲_繁-A.command**」：
   - 自動將應用程式複製至目前使用者的個人輸入法目錄：`~/Library/Input Methods/行雲_繁-A.app`。
   - 自動透過 `codesign` 進行本機 ad-hoc 簽名與快照驗證。
   - 自動於 LaunchServices 核心資料庫中註冊正式唯一路徑，並註銷 DMG 映像檔或歷史建置副本。
   - 自動調用 macOS Carbon TIS（Text Input Source）API 將輸入法啟用並登記於選單列。
   - 若系統已有舊版本，會自動安全覆蓋更新，無需手動刪除舊版。

---

## 2. 完全卸載（反安裝）

1. 雙擊執行「**反安裝行雲_繁-A.command**」：
   - **平順轉移輸入源**：若當前正處於行雲輸入法狀態，腳本會先自動切換至系統其他可用輸入法（如 ABC），解除佔用。
   - **終止背景進程**：安全結束 `UnifyIME` 等常駐進程。
   - **徹底刪除實體檔案**：從 `~/Library/Input Methods/` 移除 `行雲_繁-A.app` 目錄。
   - **撤銷系統註冊**：調用 `lsregister -u` 註銷所有已記錄的 app 副本，並重整系統輸入法守護程序（`TextInputMenuAgent`, `TextInputSwitcher`）。
   - **停用 TIS 句柄**：調用 `TISDisableInputSource`，確保快捷鍵（Control + 空白鍵）與選單列完全不再出現。

---

## 3. macOS 系統設定之安全設計與限制說明（重要）

### 為什麼反安裝腳本無法自動刪除「系統設定」介面內的清單項目？
1. **蘋果 TCC / SIP 系統級防護**：
   - macOS（Sonoma / Sequoia / 27.0）將使用者的輸入法啟用清單儲存於受保護的系統偏好設定檔（`~/Library/Preferences/com.apple.inputsources.plist`）。
   - 蘋果為了防止惡意軟體在背景偷偷置換使用者的預設輸入法或安裝鍵盤側錄器，對該檔案施加了嚴格的強制存取控制（`com.apple.macl` 屬性）。
   - **任何第三方腳本或終端機指令（即使具備 root / sudo 最高管理員權限）都無法直接竄改此設定檔**，否則系統內核會直接拋出 `Operation not permitted`。
2. **所有 macOS 輸入法的標準行為**：
   - 包含唯音（vChewing）、鼠鬚管（Rime / Squirrel）、Yahoo! 奇摩輸入法等所有第三方輸入法，皆受此系統機制約束。
3. **使用者最後清理步驟**：
   - 執行完反安裝腳本後，若開啟 macOS「系統設定」>「鍵盤」>「文字輸入方式」（編輯）時仍看得到「行雲_繁-A」歷史項目：
   - **只要在該視窗中點選「行雲_繁-A」，並按下左下角的「—」（減號）按鈕**。
   - 該項目即立刻自系統清單永久移除；因底層 App 已被刪除，未來按「+」也不會再看到它。
