# 行雲_繁-A (Floating Cloud IME) 安裝與解除安裝操作指南

本文檔記錄「行雲_繁-A」輸入法的安裝、更新與解除安裝作業流程，並說明 macOS「系統設定」與輸入來源狀態之處理方式。

---

## 1. 快速安裝

1. 掛載發布的 `行雲_繁-A_安裝磁碟.dmg`（或 `XingYun_v1.2.1.dmg`）。
2. 雙擊執行「**安裝行雲_繁-A.command**」：
   - 將應用程式複製至目前使用者的個人輸入法目錄：`~/Library/Input Methods/行雲_繁-A.app`。
   - 透過 `codesign` 進行本機 ad-hoc 簽名。
   - 於 LaunchServices 核心資料庫中更新應用程式路徑索引。
   - 調用 macOS Carbon TIS（Text Input Source）API 將輸入法啟用並登錄於選單列（若已啟用則略過重複調用，降低狀態異常風險）。
   - 若系統已有舊版本，會覆蓋更新檔案。

---

## 2. 解除安裝（移除）

1. 雙擊執行「**反安裝行雲_繁-A.command**」：
   - **切換輸入來源**：若當前正處於行雲輸入法狀態，腳本會先嘗試自動切換至系統其他可用輸入法（如 ABC），降低使用中解除安裝失敗的機率。
   - **終止背景程序**：結束 `UnifyIME` 等常駐背景程序。
   - **移除應用程式本體檔案**：從 `~/Library/Input Methods/` 刪除 `行雲_繁-A.app` 目錄。
   - **註銷系統索引**：調用 `lsregister -u` 註銷已記錄的 App 路徑，並請求系統輸入法服務（`TextInputMenuAgent`, `TextInputSwitcher`）重新載入。
   - **停用 TIS 輸入來源**：調用 `TISDisableInputSource`，使快捷鍵與輸入法選單不再選用該模式。

---

## 3. macOS 系統設定與輸入來源狀態說明

### 為什麼執行移除腳本後，「系統設定」介面可能仍顯示該項目？
1. **系統偏好設定快取與保護機制**：
   - 在部分 macOS 版本與系統狀態下，直接透過腳本修改相關偏好檔可能不會立即反映於「系統設定」介面，且偏好檔案亦可能受到系統權限與沙盒保護。
   - 因此，不建議依賴背景指令強制修改全域設定，而應配合 macOS 原生介面完成最後清理。
2. **所有第三方輸入法的常見情況**：
   - 包含唯音（vChewing）、鼠鬚管（Rime / Squirrel）等第三方輸入法，在移除後均可能於系統設定中暫留項目顯示。
3. **使用者手動清理步驟**：
   - 執行完移除腳本後，若開啟 macOS「系統設定」>「鍵盤」>「文字輸入方式」（編輯）時仍看得到「行雲_繁-A」歷史項目：
   - **在該視窗中點選「行雲_繁-A」，並按下左下角的「—」（減號）按鈕**。
   - 移除清單項目後，若 App 本體及相關輸入法套件已刪除，通常不會再被 macOS 列為可用輸入來源；若仍出現，請嘗試重新啟動「系統設定」或登出再登入以重新整理輸入來源清單。

---

## 4. 驗證與跨版本注意事項

- **環境差異**：不同 macOS 版本（如 Ventura、Sonoma、Sequoia 等）的 LaunchServices 快取更新機制與輸入法偏好同步頻率可能有所不同。
- **可回溯之安全處理**：若在特定機器上遇到選單列殘留或系統設定列表未即時刷新的情形，手動點擊「—」（減號）或重新登入系統為最安全可靠的操作方式。
